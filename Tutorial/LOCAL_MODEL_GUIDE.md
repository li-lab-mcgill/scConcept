# Local model experimentation

Open `tutorial_4_local_model_concept_analysis.ipynb` after preparing the dataset and topic files using the quickstart and Tutorial 1. Install Ollama, download your chosen local model, change MODEL, and run cells in order. New requests and results are kept in `Results/ollama_tutorial/`.

This guide is for trying models; the manuscript reproduction workflows remain in `Tutorial2/`. Exploratory mode records validation issues without blocking usable parsed output. It does not correct hallucinated genes. Enable STRICT_VALIDATION to block such output. The notebook has passed static and simulated connection checks; end-to-end success depends on the model output and is not guaranteed.
